How are critical vulnerabilities identified and remediated directly within the Angular framework? In this episode, we speak with Jaime Burgos Tejada, widely known on GitHub as @SkyZeroZx, one of the most active and influential community contributors to the framework core.

From Lima, Peru, Jaime shares his experience solving complex bugs in @angular/core and @angular/compiler, exploring the delicate balance between fixing defects and avoiding accidental breaking changes.

Topics we cover during the conversation:
✔️ The fine line between a functional bug and a security vulnerability in Angular
✔️ Automatic sanitization, context escaping, and XSS prevention in hybrid rendering and hydration
✔️ Step-by-step methodology for isolating, reproducing, and submitting PRs to the official repo
✔️ The impact of the annual release cycle on security patches and LTS support
✔️ Strategies to shield the frontend against supply-chain attacks using pnpm and npm
